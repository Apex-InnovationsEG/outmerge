# OutMerge

One personal email to every person on your list, sent through the classic Outlook on your own Windows PC. By [Apex Innovations](https://apex-innovationseg.github.io/).

- Website: https://apex-innovationseg.github.io/outmerge/
- Latest version: https://github.com/Apex-InnovationsEG/outmerge/releases/latest/download/OutMerge.exe

This repository holds only the OutMerge download page (the `main` branch, served by GitHub Pages) and the release files. The source code is private.

Every release carries `OutMerge.exe`, `SHA256.txt` and `OutMerge.exe.sig`. OutMerge's own Check for updates accepts a new version only when its SHA-256 matches and its signature verifies with the public key built into OutMerge.
